
# AI-Based Steganography Detection System

An educational image steganography project built with Python, Streamlit, OpenCV, and Scikit-learn. It provides an interactive interface for embedding secret messages into images, extracting supported LSB payloads, and experimenting with machine learning-based image classification.

## Features

- Interactive Streamlit web application
- LSB (Least Significant Bit) message encoding and extraction
- UTF-8 message support with payload verification
- PNG download of encoded images
- Random Forest classification using LSB statistical features
- Synthetic dataset generation and model evaluation scripts
- Model performance reports and confusion matrices

## Technologies Used

## Installation

Python 3.12 is recommended for the current environment.

### Windows (PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

## Run the Application

```powershell
streamlit run app.py
```

Open the local URL displayed in your terminal, usually `http://localhost:8501`.

## How to Use

### Analyze an Image

1. Open the Analyze Image tab.
2. Upload an image.
3. Run the analysis.
4. Review the machine learning prediction and LSB payload extraction result.

### Hide a Message

1. Open the Hide a Message tab.
2. Upload a cover image.
3. Enter your secret message.
4. Generate the encoded image.
5. Download the resulting PNG and verify message extraction.

## Machine Learning Approach

The Random Forest classifier uses three LSB-based statistical features:

- LSB ones ratio
- Horizontal LSB changes
- Vertical LSB changes

The project also includes scripts for generating synthetic image datasets, training models, and evaluating predictions.

## Experimental Results

In the current experiments:

- Synthetic test dataset accuracy: 81.5%
- App-encoder compatibility experiment accuracy: 59.0%
- Message extraction succeeded for all 100 app-encoded test images.

These results come from specific experimental datasets and should not be interpreted as real-world detection accuracy. The classifier currently struggles to generalize to images encoded by the application's message-embedding function.

## Limitations

- A negative extraction result does not prove that an image is clean.
- The extractor supports this project's LSB payload format, not every steganography technique.
- Classification predictions may be incorrect.
- JPEG compression and image editing can alter embedded pixel bits.
- More diverse datasets and improved feature engineering are needed for reliable detection.

## Future Improvements

- Improve classification using diverse, independently collected image datasets.
- Train and evaluate using images generated by the same encoding method as the application.

- Add more image analysis features and improve model generalization.

## Disclaimer

This project is intended for educational and experimental purposes. Its predictions should not be treated as definitive evidence that an image does or does not contain hidden information.
